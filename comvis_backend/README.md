# Driver Fatigue Detection - Backend Server

Ini adalah server backend berbasis Flask dan OpenCV untuk mendeteksi kelelahan pengemudi menggunakan Eye Aspect Ratio (EAR) dan 68 Facial Landmarks dari Dlib.

Server ini di-deploy menggunakan Docker dan berjalan pada port 7860 sesuai standar Hugging Face Spaces.
